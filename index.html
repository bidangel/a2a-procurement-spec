A2A Procurement Profile

Draft v0.1 (in flight). Expect breaking changes until v1.0.

A draft agent-to-agent procurement interoperability profile layered on existing UBL 2.3, Peppol BIS Pre-Award, OCDS 1.1.5 and EU eForms semantics. The canonical types align field by field with those vocabularies wherever a mapping exists, and add new terms only where the agent-to-agent workflow has no existing fit.

This site serves the machine-readable artifacts. The prose (ADRs, crosswalks, governance) is published in the source repository.
