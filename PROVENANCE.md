# Provenance

This file is regenerated by the upstream `pnpm spec:export` pipeline.
Each entry maps a published file in this repository to the source SHA
in the upstream BidAngel platform repository at the time of export.

> **Status:** placeholder. The first content drop (ADRs + crosswalks)
> will be exported once the `chore/spec-export-script` PR lands
> upstream. Until then, this repository contains only the bootstrap
> meta-files (README, GOVERNANCE, CONTRIBUTING, licenses).

## Format

```
<published-path>  <upstream-source-path>  <upstream-source-sha>
```

The upstream source SHA is the commit at which `pnpm spec:export` was
last run.
