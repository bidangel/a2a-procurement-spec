Vocabulary namespace v0.1

Draft. Expect breaking changes until v1.0.

https://spec.bidangelai.com/v0.1/ is the namespace IRI of the A2A Procurement Profile v0.1 vocabulary. The JSON-LD contexts bind it to the a2a: prefix and use it as @vocab.

A term keeps the UBL 2.3 IRI when it corresponds exactly to a single UBL element. It is defined in this namespace otherwise. The crosswalks record the UBL, Peppol BIS Pre-Award, OCDS 1.1.5 and EU eForms mapping for every term.

Contexts

The context files are the normative source. One per canonical fragment:

  • requirement.context.jsonld
  • opportunity.context.jsonld
  • evaluation-criterion.context.jsonld
  • buyer.context.jsonld
